# 来源准入与采集约束

当前只有本地合成来源，`network_enabled=false`，不会请求example.org或任何真实竞赛网站。

## 接入真实来源前填写

| 项目 | 需记录的内容 |
|---|---|
| 官方身份 | 主办方或高校部门身份依据，不只看域名 |
| 采集依据 | 条款、获准接口、RSS说明或明确授权 |
| robots | 检查时间、适用User-Agent、可访问路径 |
| 白名单 | 域名、路径、允许的重定向目标 |
| 频率 | 网站要求、域名并发、最小间隔、每日上限 |
| 留存 | 是否允许正文/附件快照，允许公开的摘要范围 |
| 负责人 | 维护者、联系途径、复查日期 |
| 停止条件 | 禁止采集、登录、验证码、401/403、持续429、页面异常 |

## 必须实现的行为

- robots不是授权证明；公开内容不等于允许无限采集或转载。
- 未准入时拒绝联网。未知状态、无法可靠校验时先暂停。
- 禁止绕过登录、验证码、访问控制和反爬；禁止账号池、验证码破解和代理轮换绕过限制。
- 优先获准API/RSS，列表低频增量检查；请求间隔遵守更严格要求。
- 所有重定向重新检查域名、路径、协议及解析后的IP，不访问本机、内网、链路本地和元数据地址。
- 设置连接/读取超时与响应大小上限；不执行网页脚本。
- 429遵守Retry-After；401/403和验证码进入暂停，不反复请求。
- 页面结构变化和“没有更新”分别记录；字段缺失突增时停止自动发布。
- 资格、截止时间、报名入口保留原文与版本，真实数据发布前人工核验。
- 不采集报名名单、身份证、手机号或账号信息；不全量公开转载来源全文。

参考：[RFC 9309](https://datatracker.ietf.org/doc/html/rfc9309)。
