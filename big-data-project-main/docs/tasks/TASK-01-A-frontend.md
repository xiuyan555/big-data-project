# TASK-01 · A：完善赛事详情与组合筛选

负责人：A。审查：B、D。建议分支：`feat/a-detail-filters`。

## 要交付的结果

学生能按方向和截止情况组合筛选赛事，快速看懂资格、时间与证据，并在手机上完成订阅。

## 从这里开始

- `frontend/src/App.vue`：当前页面状态、筛选与详情弹窗。
- `frontend/src/components/CompetitionCard.vue`：赛事卡片。
- `frontend/src/views/ProfileView.vue`：画像表单。
- `frontend/src/types.ts`、`api.ts`：共享类型和请求入口。

## 任务范围

- 把赛事详情和筛选区拆成独立组件，保留当前API契约。
- 增加“7天内截止 / 30天内截止 / 时间待确认”的组合筛选，日期精度不足不能伪装为精确时间。
- 详情完整展示专业、培养层次、年级和学校限制，显示来源证据、版本和演示标记。
- 增加提醒提前量选择，提交已有`lead_hours`字段。
- 为弹窗增加焦点管理、Escape关闭和键盘可操作性。
- 完善加载、空结果、未登录、接口失败及重复提交状态。

## 验收

- 分类、关键词和截止筛选可以组合；清空后恢复全部结果。
- 仅日期、未知时间、已截止不会被错误归入精确倒计时。
- 手机宽度390px无横向滚动，能完成画像、详情和订阅。
- 选择提前量后，订阅页面展示正确小时数。
- 页面不展示“保证符合资格”或“保证获奖”等无依据结论。
- `pnpm build`通过；PR附桌面与手机截图、一次完整订阅操作说明。

不接入新UI框架、不自行重命名API字段。需要新增数据时先与B确认。
