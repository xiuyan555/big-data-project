# 来源台账与准入检查

本目录记录所有候选竞赛来源的准入结论与依据，是采集开关、审核发布与定期复查的唯一依据。

## 一、台账字段

| 字段 | 含义 | 取值说明 |
|---|---|---|
| source_id | 来源编号 | 稳定短编号，例如 src-001 |
| name | 来源名称 | 主办方或高校部门名称 |
| base_url | 来源主页 | 站点根地址 |
| terms_url | 条款地址 | 服务条款或使用说明链接 |
| robots_status | robots 状态 | allow、deny、absent、unknown |
| allowed_paths | 可采路径 | 允许采集的路径，多个用分号分隔 |
| interval_seconds | 采集间隔 | 单位为秒，按低频采集设置 |
| retention_days | 留存天数 | 原文与证据的保留期限 |
| policy_status | 准入结论 | allowed、pending、rejected |
| review_date | 复查日期 | 下一次复核时间，格式为 YYYY-MM-DD |
| notes | 备注 | 拒绝或待确认的原因 |

## 二、准入结论

- allowed：允许采集，可以开启网络开关。
- pending：待确认，不得开启网络开关。
- rejected：拒绝采集，需记录拒绝原因。

## 三、准入检查清单

- [ ] 来源身份明确，属于主办方或高校官方部门。
- [ ] 服务条款允许访问与内容留存。
- [ ] robots 协议允许目标路径。
- [ ] 目标页面无需登录、验证码或特殊授权。
- [ ] 采集频率符合站点要求。
- [ ] 内容留存范围与期限明确。
- [ ] 复查日期已登记。

## 四、使用规则

1. 未确认来源不得开启采集开关。
2. 公开可读或 robots 允许不能替代完整准入。
3. 每次复查更新 policy_status 与 review_date，并在 notes 中记录原因。
4. 来源结构变化或访问受限时先暂停来源，再按清单重新确认。
